# **https://hoangduong92.github.io/exam-prep-web/**

Ôn tập **offline** — chạy tốt cả khi mất sóng (trên tàu điện). Không cần cài app từ App Store.

## Cài vào màn hình chính (làm 1 lần, khi còn wifi)

1. Mở link trên bằng **Safari** (nếu bấm từ app GitHub thì chọn **Mở trong Safari** trước).
2. Đợi vài giây cho trang tải xong (lúc này nó tự lưu offline).
3. Bấm nút **Chia sẻ** ⬆️ → **Thêm vào MH chính** → **Thêm**.
4. Từ giờ mở app bằng icon vừa tạo — chạy được cả khi **không có mạng**.
